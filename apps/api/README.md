# @leak/api

Leak's off-chain data service. Serves exactly the five endpoints that
`packages/leak-sdk/src/client/` calls, plus `GET /openapi` and `GET /healthz`.

Full reference: [`../../docs/api.md`](../../docs/api.md).

## Why the response shapes are locked

`packages/leak-sdk/src/client/` is generated by `@hey-api/openapi-ts` from this service's
OpenAPI document. The generated types — not any prose description — are the source of
truth about the API surface.

A change to a response shape here silently breaks the SDK unless the client is regenerated.
`test/client-parity.test.ts` enforces the link: it fails when the OpenAPI document and the
checked-in generated client disagree.

## Running

```bash
cp .env.example .env
pnpm exec drizzle-kit migrate
pnpm run dev
```

Or bring up the whole stack with docker; see [`../../docs/development.md`](../../docs/development.md).

## Testing

```bash
pnpm run test
```

Tests run against a **real Postgres**, not a mock. `LEAK_DATABASE_URL` must point at a
database whose migrations have been applied — the tests `TRUNCATE` between cases, they do
not create schema.

Use a database separate from graph-node's. This service runs drizzle migrations;
graph-node owns the schema in its own database, and pointing both at one database corrupts
both.
